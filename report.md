Как в проекте применяются принципы SOLID
- 
**Принцип единственной ответственности (SRP):**
- Класс `JpaProductService` отвечает только за бизнес-логику работы с продуктами.
- Контроллер `ProductController` обрабатывает HTTP-запросы и делегирует выполнение сервису, не беря на себя лишних обязанностей.
- Классы `DTO` отвечают только за передачу данных между слоями.

**Принцип открытости/закрытости (OCP):**
- Использование интерфейсов `ProductService` и `ProductRepository` позволяет расширять функциональность без изменения существующего кода.
- Миграции Liquibase добавляются через новые файлы changelog, не изменяя существующие.

**Принцип подстановки Лисков (LSP):**
- Класс `JpaProductService` реализует интерфейс `ProductService`, и его можно заменить любой другой реализацией интерфейса без изменения клиентского кода.
- Репозитории наследуются от `JpaRepository`, обеспечивая совместимость и заменяемость.

**Принцип разделения интерфейсов (ISP):**
- Интерфейсы `ProductService` и `ProductRepository` содержат только те методы, которые необходимы. Они не включают избыточных методов, которые не используются контроллерами.

**Принцип инверсии зависимостей (DIP):**
- Контроллер зависит от абстракции `ProductService`, а не от конкретной реализации.
- Сервис `JpaProductService` зависит от `ProductRepository`, а не от конкретной реализации JPA.

**Структура пакетов:** 
-
- Controller - обрабатывает HTTP-запросы.
- DTO - объекты для передачи данных между слоями.
- Exception - Кастомные исключения. 
- Model - представляет сущности БД.
- Repository - взаимодействует с базой данных.
- Service - содержит бизнес-логику.

Такая структура позволяет новым разработчикам быстро ориентироваться в проекте. Содержит Четкие границы между компонентами. Соответствует принципу единственной ответственности, так как каждый пакет отвечает за конкретный аспект.

**Преимущества DTO:**
-
- Позволяет передавать пользователю только нужную ему в данный момент информацию, снижая нагрузку и обеспечивая безопасность данных.
- Позволяет легко изменять структуру передаваемых данных.
